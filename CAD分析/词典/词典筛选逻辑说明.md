## 二、开放词的切分与清洗规则

1. **切分**：按标点（，、；。！？空格／等）将整段作答切为词条。
2. **编号剥离**：去掉被试自加的行首序号（"1.可恶" → 可恶）与词尾粘连数字
   （"两面三刀2" → 两面三刀；词中数字按分隔处理，"膈应5反胃" → 膈应 + 反胃）。
3. **错别字修正**：隔应→膈应、做呕→作呕、小巧→小瞧、看清→看轻、方案→反感、
   雎不起→瞧不起、顾不了一屑/不惜一顾→不屑一顾、明名不副实→名不副实、
   令人不是→令人不适、自欺其人→自欺欺人 等（见清洗报告）。
4. **删除规则**：
   - 整句/口语感叹句（"笑不活了就这"、"你无敌了孩子"、"什么档次搞这种"等）；
   - 谐音歧义词（出生、史一样）——正常文本会大量误命中；
   - 形容词变体（真X、很X、X的、X了、X极了、X死了、X到家 等，核心词已在词典）；
   - 动词短语变体（看了X、看着就X、让人X、感到X、十分X、万分X、简直X 等
     ≥4 字且含词典核心词者）——如"看着就烦"；
   - 包含更短同义词（≤3 字词内含词典已有词，如"心生厌恶"含"厌恶"）；
   - 错类情绪词（如厌恶题下出现"痛苦""想哭"）。
5. **保留原则**（依据被试真实表达）：
   - 网络俚语与轻度脏话（下头、膈应、你m、傻b 等）——真实语料表达；
   - 行为词（倒闭、抵制、远离、避雷 等）；
   - 跨类重叠词保留在多个词类（垃圾∈愤怒/厌恶/鄙视；鄙视、藐视 出现在厌恶题作答，
     一并归入厌恶类）；
   - 长短语（说一套做一套、黄鼠狼给鸡拜年、嘴上一套背后一套 等）——有独立表达价值。

## 三、分词衔接

- `CAD短语_加入jieba用户词典.txt`：≥4 字短语与英文混写词的 jieba 用户词典片段
  （格式 词语 词频 词性），共 248 条（v3 207 + 第二批新增 41）。
- 使用时与 `analysis/词典/jieba_user_dict.txt` 合并后重跑 01 分词脚本，
  jieba 会把短语切成整词，token 精确匹配即可命中。
- 命中口径：逐帖分词后与词典做精确 token 匹配计数，命中次数 / 帖内词总数做强度归一。
