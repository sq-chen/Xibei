## 方法摘要（论文"方法"部分可直接引用）

- **数据**：以"西贝/预制菜/后厨/公关/道歉"等关键词检索入库的微博帖 84,032 条（2025-09-10 16:55 ~ 2025-09-17 23:59）。
- **词典**：四类词表——虚伪（既有虚伪相关词表 89 词 + 问卷开放式作答 124 词）；
  愤怒（LIWC 简中版 anger 类目 262 词）；厌恶、鄙视（问卷开放式作答，各 116/133 词）。
  经去编号、错别字修正、子串归并（保留核心词）等清洗，共 724 词。
- **命中口径**：jieba 分词后精确 token 匹配；≥4 字短语经 jieba 用户词典整词化；
  帖级命中次数 / 帖内词总数作为强度指标。
- **统计模型**：互动量取 log 后剔除零互动帖（N=45,357），两水平模型（帖嵌套于用户，
  随机截距）纳入帖长、媒体、认证类型、事件阶段、发帖时段、同小时发帖量、用户发帖数、
  周末等控制变量；零互动用聚类稳健 logistic 作稳健性；三情绪对比用 Wald 系数相等检验；
  路径检验用 delta 法 Sobel（SE 含用户聚类）。
